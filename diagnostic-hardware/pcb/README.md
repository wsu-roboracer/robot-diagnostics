# PCB

Design and fabrication files for the diagnostics PCB hat.

- [`orin_hat_diag/`](orin_hat_diag/): the KiCad 10 project for the board. Its README has the header pinout and the LED index map.
- `PCB.Hat.for.Diagnostics_2026-10-14/`: the student's original EasyEDA Pro project, kept for reference. Its 40-pin header footprint has the wrong pitch (1.27 mm).
